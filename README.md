# Olá, eu sou o João Vitor 👋

Gosto de transformar rotinas manuais em ferramentas confiáveis: com **testes**, **documentação** e **segurança** desde o começo.

## Como eu trabalho

- **Documentar** a arquitetura com diagramas de sequência e um README padronizado (objetivo, stack, arquitetura, variáveis, execução e guia do desenvolvedor).
- **Testar** e dizer com franqueza o que **não** foi testado.
- **Segurança por desenho**: privilégio mínimo, segredos fora do código, senhas só em memória e acesso privilegiado com prazo.
- **Mudanças reversíveis**: backup, simulação (`-WhatIf`, `-SimularApenas`) e plano de volta antes de alterar qualquer coisa em produção.
